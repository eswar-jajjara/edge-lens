DEVELOPER MODEL LIBRARYBring your own classifierPyTorch export (.pt2), ONNX or TFLite · up to 100 MiB

A PT2 export supplies the reference for conversion comparisons. An ONNX or TFLite file alone supports accuracy and runtime measurement; original PyTorch conversion loss is unavailable.

Use your training preprocessing: (pixel × scale − mean) ÷ std. Supports RGB or grayscale, one fixed batch-one image input, and one [1, classes] score output. Weights-only .pth files need architecture code and must be exported first.

Fidelity search requires an uploaded PT2 model, ONNX output and separate calibration images. It may select the standard converter when no better numerical match is found.

Deployment constraints · this computer

Search budget

Search MinMax, Entropy and Percentile with per-channel/per-tensor weights, then test sensitivity-guided FP32 exclusions. Validation selects; the test set is evaluated after selection is frozen. The budget is checked between operations. Device latency and RAM constraints are unavailable.

Accuracy needs labelled images with ImageNet class IDs.

How to prepare your dataset

Use 2–1,000 JPG or PNG images in class folders, plus a root labels.json mapping each folder to its model class index (0 to class_count − 1). ZIP size: up to 50 MB. Preprocessed inputs must fit the 512 MiB budget; FP32/INT8 experiments share that budget across all three splits. Small sets only check that the workflow runs.

Use your model’s exact output class order. The sample presets use ImageNet indices; a custom two-class model might use {"cat": 0, "dog": 1}. For FP32/INT8, upload three disjoint ZIPs: calibration, validation and held-out test. Select the test ZIP below and the other two above. Renaming duplicate images does not make them separate.

    How to read a layer report

    01

    Match the boundary

    Conversions can fuse or remove operations. A missing one-to-one mapping is marked unavailable.

    02

    Inspect numerical drift

    Mean and maximum absolute error describe tensor differences. Tolerance includes absolute and relative terms.

    03

    Check the final outcome

    A changed tensor does not automatically mean a wrong prediction. Read accuracy and agreement alongside it.
